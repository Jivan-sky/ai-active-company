## 1. 为什么归「流程 / 作业」

对象表里最贴的两类：

| 候选类型 | 必填维度 | 本原料的匹配度 |
|---|---|---|
| 流程 / 作业 | 触发条件 · 输入 · 步骤与分支 · 判停 · 失败恢复 · 输出与验收 | **六维齐全**（见 §3），且「至少走通一遍的真实记录」这条**今天刚满足**（含失败分支） |
| 系统 / 工具 | 入口形态 · 观测落点 · 句柄 · 权限 · 放行方式 | 只有「入口形态 / 观测落点」有料，其余缺证据 |

**结论：就近归「流程 / 作业」。**

**越界的那部分**：WeKnora 作为一个**具体系统**的事实（监听地址、构建门槛、模型绑定、SSRF 校验）不属于这张卡 —— 那些进「系统 / 工具」类，本轮只登记为**参考**（`05-links.md`），不写进能力卡正文。

**为什么不是「系统 / 工具」**：那张表要的「句柄 / 权限 / 放行方式」我们没测（本次只跑通了检索 + 生成，没做权限与放行）。按对象表的失败模式，**没有证据的维度要留空并标注，不能用通用常识填满** —— 所以不选它当主类。

## 6. 阶段 1：整体理解（结构 → 解释 → 批判）

### 6.1 三层读法

**① 结构 —— 原料在讲什么**

| 原料 | 它的骨架 |
|---|---|
| M1 问题集 | 每条 = 问题 + 「我能在语料里对拍到的出处」；末尾 1 条是语料里**根本没有**的负例 |
| M2 跑批汇总 | 一行一条：`耗时 / 答案字数 / 引用数 / 思考字数` —— 能机器量出来的就这几列 |
| M3 实测报告 | 口径声明 → 环境与复现 → 逐条总表 → **决定性证据**（检索满分仍答错） → 检索侧问题 → 诚实条款 → 结论 → 下一步排序 |
| M4 接入评估 | ANC 要什么（四条要求）→ 它对得上哪几条（带验证等级）→ 合不合 → 落位 A/B/C → 风险表 → 下一步 |
| M5 上游议题 | 要定什么（四件）→ 为什么没定 → 选项甲乙丙 → 验收（四条）→ 卡住谁 |

**② 解释 —— 每部分主张什么**

- **M1**：能判对错的问题集，要害不在问题写得好，在于**每条都能拿回原文对拍**；再留一条**明知查不到**的负例，测的是「查不到会不会编」。
- **M2**：可判的指标是**量出来的**，不是感觉出来的。
- **M3**（本卡主张的主要来源）：
  1. 检索与生成**必须分开算分**；合成一个准确率会把主因埋掉。
  2. 「检索已命中、答案仍错」是**决定性证据**，它把归因钉在生成侧。
  3. 最坏的失败不是答不全，是**答成另一件事** —— 通顺、有结构、还带表格，内容却与原文无关甚至相反。
  4. **引用 ≠ 依据**：引了正确文档，答案仍可能相反。
  5. 该停的点：检索侧已经没有做功空间时，就停。
- **M4**：ANC 要的四条里，结构能力六项天然就有；唯一没验的那一格（实际问答质量）现在验了。
- **M5**：「零 token 直读盘」是默认件，自托管检索层是**升级件、不是默认件**；验收四条；**不替不存在的需求定结构**。

**③ 批判 —— 哪些是证据、哪些是主张、哪些是立场**

| 类别 | 具体 | 怎么处理 |
|---|---|---|
| **证据**（可复核） | Q2/Q4/Q6 的 Top1 分数与源文档逐字对拍（0.995 / 0.951 / 0.989）；M2 那一行的四个数；Q9 不编数字 | 直接可用 |
| **证据**（系统事实，**越界**） | 监听地址、构建门槛、观测到的计数器不回填 | **不进卡**，只登记为参考 |
| **主张**（判断） | 「主因在生成侧」—— 依据是「检索已命中、答案却错」，属**强推断**而非证明 | 可用，但措辞写成**限定范围内**的说法 |
| **主张**（预测，未验证） | 「换更大模型的收益比调检索更直接」—— 作者自己标的是「建议 / 预期」 | ⚠️ 不得写成结论，须标未验证 |
| **假设** | 「问题在 8B 的指令遵循能力，不在提示词模板」—— 原文用的是「更可能」 | ⚠️ 标为假设 |
| **立场** | 下一步排序把「换更大模型」排在「调检索 / 调提示词」之前 | 属作者立场，写成「本流程的默认排序」，并注明可改 |

**这批原料的自我局限（必须带进卡里，不能洗掉）**

| 局限 | 影响 |
|---|---|
| 有效分母只有 7 条；单库单域、单模型、单语料 | 「生成 0/7」是**小分母**，结论强度要如实标 |
| 没有「什么叫答对」的成文判准 —— 对拍是人肉做的 | **这正是本卡要补的那一环**：把「怎么判」写成可执行步骤 |
| 语料是本人自用样例 | 不算客户验收 |
| 只测到检索与生成 | 权限、放行、跨域、用量四项**没测** |

### 6.2 关键任务清单（查覆盖率用）

| # | 声称能解决的 | 本原料的证据 |
