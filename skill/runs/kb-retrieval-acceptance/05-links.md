## 2. 术语表（口径唯一来源）

| 术语 | 含义 | 不许的意思 |
|---|---|---|
| **对拍** | 把模型答案逐条拿回**原文出处**处核对 | 不是「看答案像不像」 |
| **命中** | 检索 **Top1** 就是出题时为该题**指定的那篇源文档** | 命中「同主题的另一篇」**不算** |
| **命中源文档** | 上一条的比率，分母是**有效题数**（不含负例） | 不含 Top2–TopK |
| **生成正确** | 答案与原文对拍一致：关键断言进了、且没说出相反或原文没有的东西 | 不是「答得通顺」 |
| **主因侧** | 失败归到「检索侧」还是「生成侧」—— 两侧修复手段完全不同 | 不是「两边都有点问题」这种含糊话 |
| **决定性条目** | **检索已命中、生成仍错**的那一条 | 不是「所有错误的条目」 |
| **假绿** | 形态完整（通顺、有结构、带表格）但内容与原文无关或相反 | 不是「答得短」 |
| **口径声明** | 写在产物最前的三句：语料是什么 / 模型是什么 / 这批数据是什么身份 | 不是免责声明 |
| **负例** | 一条**语料里根本没有**、且可被外部核验为「不存在」的题 | 不是「难题」 |

## 3. 参考区（有来源价值、不可独立执行）

| # | 条目 | 为什么不是独立卡 | 实际落点 |
