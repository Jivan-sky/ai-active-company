# 03-promote —— 晋级门（阶段 4）

## 1. 候选（阶段 3 判 `verified` 的那一组）

本轮只产生**一个**待晋级对象：把 K01–K10、K15 共 11 条收敛成一张卡 `kb-retrieval-acceptance`。

它们不是 11 个独立能力：分别是同一张卡的**前提 / 输入 / 步骤 / 判停 / 输出 / 边界**六段的内容。按「宁少勿多」，不强拆。

## 2. 五条判据

| # | 判据 | 问法 | 答 |
|---|---|---|---|
| 1 | 独立意图 | 会不提来源、单独提这件事吗？ | ✅ 会 —— 「帮我验一下这个本地检索层到底能不能用」 |
| 2 | 独立契约 | 有自己的输入 / 步骤 / 输出 / 完成标准？ | ✅ 有 —— 输入＝语料 + 带出处问题集；输出＝三个数 + 逐条对拍表；完成标准＝每条都有对拍结论 |
| 3 | 独立运行 | 不加载别的兄弟能力也能正确执行？ | ✅ 能 —— 单卡自带输入格式、判定规则、判停条件 |
| 4 | 独立复用 | 会在多任务里重复调用？ | ✅ 会 —— 每叠一层检索层就要跑一次 |
| 5 | 独立评测 | 能写出正向 / 负向 / 近邻 / 输出断言四类用例？ | ✅ 能 —— 见 `skill/kb-retrieval-acceptance/test-prompts.json`（8 条） |

**前三条必过 → 通过；后两条过两条 → 通过。判定：`promoted`。**
